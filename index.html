FAQ

Common questions

What is a virtual number for OTP?
It is a phone number you use once to receive a verification SMS (OTP) when registering a new app account. The code appears in your SIMURU dashboard, so your personal number stays private.
What happens if the OTP code does not arrive?
If no code arrives within the time limit, cancel the order and your balance is returned automatically. You only pay for numbers that actually receive a code.
